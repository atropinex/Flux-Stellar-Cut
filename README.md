# 🪐 Flux-StellarCut

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

**Flux-StellarCut** is a high-performance desktop video editor engineered for rapid timeline composition and precise media control. Designed for modern content creators, it unplugs heavy render pipelines into a sleek, responsive workspace—allowing you to ingest media, assemble multi-track timelines, apply GPU-accelerated transformations, and export high-bitrate cuts with zero friction.

---

## ✨ Features

- **🎞️ Multi-Track Timeline Engine:** Seamlessly splice, slip, slide, and arrange video and audio streams across dynamic tracks with frame-accurate snapping.
- **🎛️ Real-Time FX & Color Pipeline:** Apply non-destructive color correction, spatial transformations, opacity masks, and audio filters in real time.
- **🗃️ Smart Media Pool & Asset Management:** Automatic thumbnail generation, metadata parsing, and instant clip tagging for high-density footage collections.
- **⚡ Accelerated Rendering:** Lightweight timeline previewing paired with hardware-accelerated exports via custom FFmpeg worker threads.
- **🎨 Customizable Workspace Layouts:** Modular canvas viewports, audio mixers, and scope overlays tuned for both single-monitor and multi-screen workflows.

---

## 🚀 Tech Stack

- **Desktop Shell:** Electron
- **Language:** TypeScript
- **Frontend:** React
- **Styling:** Tailwind CSS
- **Engine & Media:** WebAssembly / FFmpeg
